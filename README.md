# Cloud-Sentinel
CCloudSentinel is an AI-based AWS security monitoring system that detects cloud misconfigurations and security risks in real time. It analyzes AWS logs to identify suspicious activities such as IAM changes, S3 bucket exposure, and access key misuse, and presents them through an interactive dashboard with alerts, security insights, and recommended fixes. The system helps organizations simplify cloud security monitoring and respond to threats more efficiently.loudSentinel is an AWS security dashboard that detects cloud risks from logs and displays alerts, insights, and recommended fixes to improve security.
